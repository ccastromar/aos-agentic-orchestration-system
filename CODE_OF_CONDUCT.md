# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for everyone who takes part: in issues, pull requests, reviews,
discussions and any other project space.

In short: be respectful and constructive, assume good faith, and keep criticism about the work.
Harassment, discrimination, personal attacks and publishing someone's private information are
not acceptable.

## Reporting

Report unacceptable behaviour to **conduct@ccmlab.cc**. Reports are read by the maintainers,
handled in confidence, and answered as soon as possible. Security vulnerabilities are not
conduct reports: follow `SECURITY.md` for those.

## Enforcement

The maintainers decide on the response following the Contributor Covenant's enforcement
guidelines: from a private warning to a temporary or permanent ban from the project's spaces.
